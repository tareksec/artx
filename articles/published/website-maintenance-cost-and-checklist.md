## The Non-Negotiable Website Maintenance Checklist

### 1. Daily & Weekly Security Hygiene
- **Off-Site Automated Backups:** Store encrypted copies of your database and media files in a completely separate cloud location (such as Amazon S3 or Cloudflare R2), never on the same web server.
- **Core, Theme & Plugin Updates:** Test updates in a staging sandbox before applying them to production to prevent broken layouts.
- **SSL / TLS Certificate Monitoring:** Ensure automatic renewal 30 days prior to certificate expiration.

### 2. Performance & SEO Audits
- **Broken Link Detection (404 Auditing):** Clean up dead internal and external links that damage crawl budget.
- **Google Search Console Indexing Review:** Verify that newly published pages are indexed without canonical conflicts or mobile usability errors.
- **Core Web Vitals Benchmarking:** Test LCP and CLS monthly to prevent gradual performance decay caused by uncompressed marketing images.

### 3. Database Maintenance & Cleanup
- Optimize MySQL/PostgreSQL database tables.
- Purge expired session transients, spam form entries, and revision logs to keep database queries sub-second fast.

### 4. Form & Payment Gateway Verification
- Submit test orders and test contact forms monthly to confirm that leads and payment confirmations actually reach your inbox and CRM without being blocked by spam filters.

## Frequently Asked Questions (FAQ)

### What happens if I don't maintain my website?
Unmaintained websites accumulate known security vulnerabilities within 3 to 6 months. Hackers scan for outdated plugins and inject malicious redirect scripts or SEO spam. Additionally, unoptimized databases slow down loading speeds, causing Google to demote your search rankings.

### Can I do website maintenance myself without an agency?
Basic tasks like updating blog articles and renewing domain names can be done in-house. However, technical tasks like offsite database restorations, PHP version compatibility fixes, and Core Web Vitals debugging require experienced software engineers.
