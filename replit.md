# ArtX Studio Website

An independent design and development studio website built with TanStack Start (React + Vite), Tailwind CSS v4, and shadcn/ui components.

## Stack

- **Framework:** TanStack Start (SSR) + TanStack Router (file-based routing)
- **Styling:** Tailwind CSS v4 with inline theme variables in `src/styles.css`
- **Components:** shadcn/ui (Radix UI primitives)
- **Animation:** Framer Motion
- **Smooth scroll:** Lenis
- **Package manager:** Bun
- **Build target:** Cloudflare (via Nitro)

## Running the project

```bash
bun install      # install dependencies
bun run dev      # start dev server on :5000
bun run build    # production build
```

## Project structure

```
src/
  content/site.ts        # All content data (projects, services, blog, pricing, team, values)
  routes/                # File-based pages
    index.tsx            # /
    work.tsx             # /work
    work_.$slug.tsx      # /work/:slug (case study detail)
    services.tsx         # /services
    services_.$slug.tsx  # /services/:slug (service detail)
    about.tsx            # /about (team, timeline, values)
    blog.tsx             # /blog
    blog_.$slug.tsx      # /blog/:slug
    pricing.tsx          # /pricing
    contact.tsx          # /contact
    sitemap[.]xml.ts     # /sitemap.xml
  components/
    animations/          # ScrollReveal, HoverCard, RotatingAsterisk
    sections/            # Nav, Hero, Portfolio, Services, Footer, BrandPhilosophy, etc.
    providers/           # SmoothScrollProvider (Lenis)
    ui/                  # shadcn/ui components
```

## Design tokens

- Background: `#FAF9F6` (cream)
- Accent: `#FF4500` (orange)
- Dark: `#1A1A1A`
- All tokens defined as CSS variables in `src/styles.css`

## Routing convention

TanStack Router uses file-based routing. The `_` suffix before a `.` (e.g. `work_.$slug.tsx`) escapes parent layout nesting. Do NOT edit `src/routeTree.gen.ts` — it is auto-generated by the Vite plugin on dev server start.

## Content

All content is props-driven via `src/content/site.ts`. To add a new case study, extend the `projects` array. To add a new blog post, extend the `blogPosts` array. Content types are fully typed.

## User preferences

- All new content must be props-driven from `src/content/site.ts`, not hardcoded in components.
- Maintain design token consistency: use `bg-background`, `text-accent`, `bg-dark` etc. — never hardcode hex values in components.
- Use `ScrollReveal` for section entrances, consistent with the rest of the site.
